# git-classroom

This is a prototype for a bachelor's thesis. The program is a Node.js CLI similar to GitHub Classroom

## One-time setup

From the project directory:

1. Run `npm install`.
2. Create `secure/.env` with the required provider client IDs.
3. Run `npm run build`.
4. Run `npm link` to make the command available in your terminal.

## Start

After setup, start the app by running:

```sh
git-classroom
```
